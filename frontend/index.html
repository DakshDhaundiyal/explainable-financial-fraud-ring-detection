Why TGAT is Selected

Strategic Alignment
✓

Resolves Static Graph Failure

Static GCN failed (0.6064 ROC-AUC) because collapsing time aggregates transactions across months into spurious static edges, propagating future information backwards.

✓

Dynamic Attention Explainability

Unlike black-box XGBoost which only outputs global feature bars, TGAT computes multi-head attention weights $\alpha_{ij}$ on past transfers, tracing exact money laundering chains.

✓

Continuous Time Encoding

Uses harmonic Fourier basis functions (Bochner's Theorem) mapping continuous time differences $\Delta t$, distinguishing rapid bursts from normal cadence.

✓

83.8% Alert Noise Reduction

The frozen operating threshold ($\tau^* = 0.7372$) slashes false positives from 2,198 down to 357, saving hundreds of compliance investigator hours daily.
